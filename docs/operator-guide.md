# Operator Guide

## Daily workflow

1. Go to `/lots`.
2. Upload invoicing export `.xlsx`.
3. Run `Dry Run`; verify preview/errors.
4. Run `Commit`.
5. Use filters and select lots.
6. Execute bulk actions:
   - Bulk Sampling
   - Bulk Sold Pending Dispatch
   - Bulk Hold/Reprint

## Dispatch advice

1. Open `/dispatch-advices`.
2. Verify generated records.
3. Export CSV for billing team.

## Dashboard monitoring

1. Open `/dashboard`.
2. Track:
   - Sold pending dispatch
   - Hold/Out backlogs
   - Overdue payments
